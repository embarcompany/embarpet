# Handoff — expansão de destinos Embarpet

## Estado atual

O site de conversão da Embarpet já possui uma landing page robusta e responsiva para os Estados Unidos. A próxima etapa aprovada pelo usuário é criar LPs reais para todos os destinos apresentados no header: Estados Unidos, Portugal, Espanha, Itália, Argentina, Uruguai e Paraguai.

Não há fase GSD, plano nem processo assíncrono ativo. O mapeamento da base foi concluído e está versionado no commit `161f241`. Este handoff e o `PROJECT.md` registram a decisão antes da troca de IA.

## Trabalho concluído

- LP `/destinos/estados-unidos` criada e refinada em desktop/mobile.
- Estrutura de destinos já é modular: `DestinationPage` recebe `DestinationLandingContent`.
- Modal único de análise integrado aos CTAs, com rota e atribuição de origem.
- Conteúdo atual de EUA centralizado em `src/features/destinations/destination-content.ts`.
- Header já mostra os sete destinos prioritários, mas somente EUA leva a URL específica.
- Mapeamento técnico em `.planning/codebase/` concluído.

## Trabalho restante

1. Transformar o registry de destinos em fonte para os sete países, preservando tipagem.
2. Criar configs de Portugal, Espanha, Itália, Argentina, Uruguai e Paraguai: slug, código ISO, bandeira, SEO, hero, copy, FAQ e três cards contextuais por país.
3. Atualizar o mega menu para apontar cada país para `/destinos/<slug>`.
4. Conferir em cada LP: rota Brasil → destino pré-preenchida, possibilidade de alterar/inverter rota, `analyticsSource` por CTA, canonical e renderização responsiva.
5. Rodar `npx tsc --noEmit`, `npm run build` e `git diff --check`; revisar links e UX manualmente.

## Decisões que não devem ser desfeitas

- **Um TSX compartilhado, múltiplas configurações:** não duplicar a página EUA para cada destino.
- **Sete destinos do header são o escopo atual:** não acrescentar Canadá, França, Alemanha ou Países Baixos antes de terminar os sete prometidos na navegação.
- **LP é de conversão:** conteúdo deve levar à análise e ao WhatsApp; não virar guia regulatório exaustivo.
- **Regras mudam:** usar linguagem condicionada à rota, espécie, companhia e data; pesquisar e datar qualquer afirmação específica antes de publicar.
- **Sem imagens geradas agora:** usar imagem real aprovada/licenciada ou deixar a escolha visual para uma etapa posterior.
- **Fidelidade ao design atual:** evitar overflow horizontal no mobile e preservar espaçamentos/CTA/modal da LP EUA.
