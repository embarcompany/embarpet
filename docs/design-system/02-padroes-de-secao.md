# Padrões de seção

Cada padrão abaixo tem uma função específica. Uma nova seção deve nascer de um destes padrões, não de uma composição isolada.

| Padrão | Pergunta que responde | Anatomia | CTA permitido |
|---|---|---|---|
| Hero de conversão | “Como começo?” | hook + prova compacta + entrada de rota + mídia operacional | conversão |
| Faixa de embarques | “Isso acontece de verdade?” | fotos reais em sequência; leitura contínua e arrastável | nenhum |
| Prova operacional | “Eles têm repertório para meu caso?” | mosaico real + métrica/credencial + leitura integrada | navegação interna |
| Modalidades | “Quais possibilidades existem?” | introdução explicativa + rail de quatro cards equivalentes | `Saiba mais` interno |
| Equipe | “Quem cuida disso?” | retrato humano + cargo + dor resolvida + capacidade operacional | navegação interna |
| Método | “Como a complexidade vira plano?” | etapas cronológicas conectadas; verbo + resultado de cada etapa | conversão |
| Na mídia | “Quem reconhece esse conhecimento?” | destaque editorial/vídeo + matérias com logo e origem | mídia / link externo |
| Histórias reais | “Já resolveram algo parecido?” | case com rota, contexto, foto autorizada e relato | navegação interna |
| PetLuxo | “Existe acompanhamento dedicado?” | bloco premium escuro/dourado + escopo + três marcos | `Saiba mais` interno |
| Destinos | “Meu país muda o plano?” | pergunta de país + destinos prioritários + benefício de análise | inicia análise contextual |
| FAQ | “O que ainda preciso entender?” | dúvidas de intenção de busca + resposta direta | guia ou análise contextual |
| CTA final | “Posso avançar mesmo sem saber tudo?” | síntese curta + ação principal | conversão |

## Regras de composição

- Toda seção começa com uma entrada reconhecível: eyebrow/pílula curta, título de uma ideia e, quando útil, texto de apoio.
- Títulos de destaque usam uma palavra ou trecho em turquesa; PetLuxo usa dourado. Nunca aplicar fundo marcado ao destaque.
- Não separar seções por linhas decorativas. Diferenciar por ritmo, fundo, mídia e conteúdo.
- Não empilhar cards por hábito. Cards existem quando o usuário compara, escolhe ou precisa de evidência delimitada.
- O espaço entre seções deve seguir o mesmo ritmo vertical; uma pausa maior só existe quando a história troca de assunto.
- Em mobile, largura útil é total dentro da margem segura; pílulas e títulos podem centralizar apenas em seções editoriais. Formulários e conteúdo de decisão mantêm leitura à esquerda.

## Padrão de card por intenção

| Tipo | Conteúdo mínimo | Interação |
|---|---|---|
| Modalidade | foto, nome, como funciona, aviso aplicável, CTA interno | elevação/borda sutil no hover; mesma altura em todos |
| Editorial/mídia | logo/fonte, tema, link | feedback de navegação, sem competir com CTA principal |
| Processo | número, ação, explicação | conexão visual cronológica; sem aparência de produto à venda |
| Prova/case | imagem, rota, contexto, resultado verificável | arraste desktop / carrossel mobile |
