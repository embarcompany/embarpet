# Arquiteturas de página

## 1. Index institucional conversiva

```text
Hero de rota
→ Faixa de embarques reais
→ Prova operacional
→ Modalidades
→ Equipe Embarpet
→ Método Embarpet
→ Embarpet na mídia
→ Histórias reais
→ PetLuxo
→ Destinos
→ FAQ
→ CTA final
→ Footer
```

**Trabalho:** capturar intenção ampla, apresentar possibilidades sem prometer, provar capacidade e levar para o diagnóstico.

## 2. Página de modalidade

```text
Contexto da modalidade
→ O que é / como costuma funcionar
→ Quando pode fazer sentido
→ Pontos de atenção e regras condicionais
→ Prova ou caso relevante
→ FAQ específico
→ Iniciar análise contextual
```

**Nunca:** tratar uma modalidade como garantia; esconder critérios importantes; usar CTA de avião para “saiba mais”.

## 3. Página de destino

```text
Hero: país + intenção de rota
→ O que muda nesse destino
→ Etapas e documentos a confirmar
→ Situações que variam por pet/companhia
→ Guia/FAQ com fontes e data de revisão
→ Diagnóstico com destino pré-preenchido
```

**Objetivo:** ser útil para busca e IA sem simular parecer definitivo. Atualização e fontes fazem parte da interface.

## 4. Serviço premium / PetLuxo

```text
Proposta dedicada
→ Escopo de acompanhamento
→ Marcos da jornada
→ Vídeo/prova humana
→ Perguntas frequentes
→ Solicitar análise
```

**Direção:** fundo escuro, destaque dourado, tom mais exclusivo; a lógica de CTA continua a mesma.

## 5. Guia editorial

```text
Breadcrumb
→ título + resposta curta
→ metadados: fonte/revisão/autoria
→ conteúdo escaneável
→ callouts e fontes
→ FAQ relacionado
→ diagnóstico contextual
```

## 6. História real

```text
Rota + contexto
→ desafio
→ participação da Embarpet
→ resultado autorizado
→ depoimento/fonte
→ próxima história ou análise
```

## 7. Obrigado / continuidade no WhatsApp

```text
Confirmação dinâmica e não sensível
→ CTA dominante “Continuar pelo WhatsApp”
→ microcopy de segurança
→ prova social
→ vídeo/conteúdo leve
→ fallback secundário
```

Esta rota não é indexável nem aparece no sitemap. Registrar `form_submitted`, `diagnostico_concluido`, `thank_you_view`, `lead_created`, `whatsapp_click_after_form` e `lead_continued_whatsapp` conforme consentimento.
