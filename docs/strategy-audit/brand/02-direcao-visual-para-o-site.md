# Tradução da IDV para o novo site

## Aplicação aprovada pela fonte

| Área | Direção |
|---|---|
| Header | marca clara, hierarquia forte e poucos elementos concorrentes |
| Hero | visual premium, limpo, técnico e humano; no máximo uma ou duas imagens relacionadas à viagem |
| Diagnóstico | grids previsíveis, rótulos claros, campos alinhados e navegação por teclado |
| CTA | usar turquesa institucional para ação concreta; evitar promessas de resultado |
| Cards | borda fina, cantos moderados, pouca sombra e informação escaneável |
| Guias | uma ideia por seção, exemplos, chamadas de atenção e sínteses; sem paredes de texto |
| Rodapé | compacto, legível e visualmente secundário |

## Inferência para o institucional conversivo

- Hero com fundo branco, H1 em `--teal`/`--ink`, diagnóstico dominante e CTA turquesa.
- Fotos reais de tutores/pets/equipe são preferíveis a imagens genéricas; usar assets existentes somente após validar licença e contexto.
- Modalidades devem usar cards comparáveis: quando se aplica, o que varia, pontos de atenção e próximo passo.
- Usar callouts semânticos para “atenção”, “dica” e “fonte oficial”; separar regra sanitária, regra de companhia e orientação de bem-estar.
- Autoridade entra no contexto: credenciais com link de validação, fontes datadas e cases rastreáveis.

## Acessibilidade

Foco visível, rótulos persistentes, texto alternativo em imagens informativas, feedback textual além de cor e respeito à preferência de redução de movimento. Metas WCAG exatas precisam ser confirmadas.
